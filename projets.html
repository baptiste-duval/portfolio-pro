Retrouvez ici l'ensemble de mes travaux réalisés en Bachelor R&T. Chaque projet (SAE) valide un bloc de compétences spécifique, allant de l'infrastructure réseau à la sécurité informatique[cite: 17, 21, 22].

Semestre 1 - Fondamentaux

SAE 1.1 : Sensibilisation au risque numérique

Dans le rôle d'un RSSI, j'ai élaboré une stratégie de sensibilisation pour protéger les collaborateurs contre les cybermenaces liées à l'erreur humaine.

SAE 1.2 : S'initier aux réseaux informatiques

Ce projet visait à concevoir et déployer une infrastructure réseau complète, de la topologie logique sous Draw.io à la configuration réelle d'équipements Cisco.

SAE 1.3 : Découvrir un système de transmission

Etude des caractéristiques physiques des supports de transmission, comme l'atténuation et le retard de propagation des signaux.

SAE 1.4 : Se présenter sur Internet

Conception et déploiement de mon identité numérique professionnelle.

Semestre 2 - Approfondissement

SAE 2.1 & 2.4 : Projet Pépinière (Creil-Society)

Déploiement complet d'un Système d'Information pour une entreprise fictive. Ce projet intègre une infrastructure réseau sécurisée, des services web haute disponibilité et de la communication unifiée[cite: 17, 18, 22].

Services Web & BDD

Architecture Docker-Compose incluant Flask, MySQL (Primaire/Replica) et Nginx pour la sécurité SSL/TLS[cite: 17, 21].

Docker Flask MySQL Nginx

Réseau & Sécurité

Mise en œuvre d'un portail captif PfSense avec authentification LDAP sur Windows Server et routage inter-VLAN.

PfSense LDAP Active Directory

Service Vidéo (Streaming)

Configuration d'un flux vidéo UDP via FFmpeg pour la diffusion sur le réseau interne.
