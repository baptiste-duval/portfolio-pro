Cursus Académique

Retrouvez ici l'ensemble de mes travaux réalisés en Bachelor R&T. Chaque projet (SAE) valide un bloc de compétences spécifique, allant de l'infrastructure réseau à la sécurité informatique, en passant par le développement d'outils professionnels.

Semestre 1 - Fondamentaux

SAE 1.1 : Sensibilisation au risque numérique

Dans le rôle d'un RSSI, j'ai élaboré une stratégie de sensibilisation pour protéger les collaborateurs contre les cybermenaces liées à l'erreur humaine.

SAE 1.2 : S'initier aux réseaux informatiques

Ce projet visait à concevoir et déployer une infrastructure réseau complète, de la topologie logique sous Draw.io à la configuration réelle d'équipements Cisco.

SAE 1.3 : Découvrir un système de transmission

Etude des caractéristiques physiques des supports de transmission, comme l'atténuation et le retard de propagation des signaux.

SAE 1.4 : Se présenter sur Internet

Conception et déploiement de mon identité numérique professionnelle.

Dépôt GitHub & Fichiers sources

Accédez au code source et à la documentation du projet.

Semestre 3 - Spécialisation

SAE 3.01 : Mise en œuvre d'un système de transmission

Projet de transmission sans fil avec ADALM-Pluto et GNU Radio. Analyse de spectres GSM/LTE et transmission vidéo en UDP.

SAE 3.02 : Développer des applications communicantes

Développement d'une application Client/Serveur en Python 3 permettant la recherche multi-formats (TXT, HTML, PDF, Excel) via des mots-clés ou expressions régulières (Regex).

Architecture du projet

Technologies Clés

  • Backend : Flask, Pandas, BeautifulSoup
  • Frontend : Interface Graphique Tkinter
  • Parsing : pdfplumber & Regex engine
  • Standards : Respect de la norme PEP 8
